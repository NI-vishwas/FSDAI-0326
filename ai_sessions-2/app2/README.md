# Weather LLM Agent understanding and Working app
A weather LLM agent
- Create a `.env` file and add the openai key with as in example
- Pre-requisites: Dependencies mentioned in parent `pyproject.toml file`
- This application needs OPEN_WEATHER_API_KEY. This can be created at [Open Weather API](https://openweathermap.org)
- Add to Env File
- Run the application using 

```bash
python app.py
```
